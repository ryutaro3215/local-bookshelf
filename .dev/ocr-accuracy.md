## 「正解」の定義

正規化した候補と正規化した正解題名が**完全に一致**したものを正解とする。

- 正規化: ① Unicode NFKC（全角英数→半角など）② 小文字化 ③ 空白・改行、約物（Unicode の Punctuation。「」〈〉・、。！？ など）、記号（Unicode の Symbol）を除く。長音「ー」・かな・漢字・英数字は残す（実装: BookshelfTests/TitleRecognizerTests.swift の `TitleMatch.normalize`）
- 例（架空の題名）: 「星は「なぜ」光るか」と「星はなぜ光るか」は一致。「月の」と正解「月の地図」は不一致（題名の一部だけ）
- 指標:
  - **先頭の候補が正解（top-1）**: 題名欄の初期値がそのまま使える
  - **候補内に正解**: 5件の候補のどれかを選べば済む
  - **候補が題名を含む（参考）**: 候補の中に正解題名を含むものがある（余計な文字を消せば済む。例: 英字の前置き・版表示がついたもの）
- 正解題名は副題・シリーズ名・巻数を含まない書名本体（manifest.json の title、raw-titles.json の title）

## 不正解の傾向（番号のみ）

- 1文字の誤読（字形の似た漢字・中黒の欠落・装飾書体の1文字目）: C01・R14・R10・C32・R19・C26
- 題名が別の大きな文字（帯のキャッチコピー・隣に写った別の本・店の看板）に負け、先頭にならない: C00・R13・C26・R09・R18・R19
- 題名が2行・2列に分かれ、間に小さな文字（英題など）が挟まる・行の大きさがそろわないため、つなげられない: C20・C11・R24・C34・R12
- 縦書きと横書きが混ざった題名: C08（R21 は正解）
- 題名の前後に余計な文字（英字の前置き・版表示）がつく（CT）: C04・R17・C09・R22
- 正解題名の扱いの確認が必要: C11（manifest.json の題名は表紙の題名の途中まで）・R24（表紙のとおり最後まで）
