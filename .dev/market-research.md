# マーケットリサーチ要点（書籍管理アプリ向け抽出）

出典: /Users/rmatsuba/Dia/Foreign Apps Market Research.md（全文はそちらを参照）

## 前提となる戦略
- 端末完結（ローカルファースト）: サーバー/外部API費ゼロ → 限界費用ゼロ、利益率80〜85%以上
- クラウドAPI従量課金のリスク回避（Crouton は画像認識APIが週約$2万になる試算でオンデバイスへ転換）
- プライバシー訴求: 「データを外部に送らない」こと自体が差別化要因
- Apple Small Business Program で手数料15%

## 書籍管理アプリに転用できる成功パターン
| 参考アプリ | 転用できる要素 |
| :-- | :-- |
| Crouton（レシピ管理, ADA 2024） | オンデバイスOCR（Vision/Core ML）で紙→構造化データ化。分散した情報源を個人の一元ライブラリに集約。登録数上限フリーミアム |
| HabitKit（習慣トラッカー, MRR $31k+） | GitHub風グリッドなど視覚的な継続可視化、ウィジェット、アカウント不要。初日から有料、ASOで流入98%オーガニック |
| Bobby（サブスク管理） | 外部連携しない手動管理＋プリセットで入力負担を最小化。機能解放型の買い切りIAP |
| Swipewipe（写真整理） | 退屈な整理作業をスワイプ等のマイクロインタラクションでゲーム化 |

## 日本市場での勝ち筋（レポートの一般原則）
- ASO: アプリ名の先頭に最重要キーワード（例:「読書記録」「本棚」）、ブランド名は後置
- 極小MVP: 単一コアループを磨いて数ヶ月以内にリリースし、価格受容性を早期検証
- ハイブリッド課金: 月額/年額サブスク＋上位に買い切り（日本は買い切り選好が強い）
- 日本特有のローカライズがそのまま参入障壁になる
